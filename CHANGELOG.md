# Changelog

## v1.0.0-beta.1 — 2026-10-13

- Added 6 selectable UI languages with English as the default and local preference persistence.
- Introduced a compact dynamic timeline: shows one V1 track by default and reveals T1/T2, V2 and A1/A2 when used.
- Added manual + Track menu, kept 12 V9 transitions, keyframes, filters, GIPHY preview and vector library.
- Cleaned up labels, technical status text and duplicated explanations.
- Added Windows build workflow, package metadata and public beta documentation.
- Improved loopback server origin/host restrictions.

This is a beta intended for evaluation, not a feature-complete Clipchamp or Canva replacement.
